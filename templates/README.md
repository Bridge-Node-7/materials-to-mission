# Authoring Templates

These files are worked synthetic authoring templates.

They are not real cases, approved forms, qualification records, or authorization to place
private evidence in the public repository.

## Use

1. Copy a template outside the public repository.
2. Replace every fictional value.
3. Preserve the released schema identifiers.
4. Validate locally.
5. Keep real records in an approved private system.
6. Publish no derivative without separate written authorization.

## Authoring order

```text
Decision
Human authority
Requirements
Evidence
Unknowns and contradictions
Governing weak link
Options
Disposition
Action, proof, and reassessment
```

`examples/` contains the canonical completed synthetic reference. `templates/` contains
fictional authoring aids. Neither location may contain real supplier, customer, laboratory,
sample, lot, facility, price, capacity, vulnerability, controlled, export-controlled, or
patent-sensitive data.
