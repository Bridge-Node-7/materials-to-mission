# Private Case Readiness Checklist

## Authority

- [ ] Responsible entity and data owner identified
- [ ] Authority to use evidence documented
- [ ] Named human decision owner
- [ ] Named disposition authority
- [ ] Independent reviewer identified
- [ ] Publication authority identified

## Handling

- [ ] Confidentiality terms approved
- [ ] Private system of record approved
- [ ] Access, retention, deletion, backup, and incident response approved
- [ ] Cloud-sync behavior reviewed
- [ ] Git and public-repository exclusion confirmed

## Restrictions

- [ ] Export-control and controlled-information review
- [ ] Privacy review
- [ ] Intellectual-property and patent review
- [ ] Contractual-use restrictions reviewed
- [ ] Approved AI-use boundary documented

## Case design

- [ ] Bounded decision and intended user
- [ ] Decision deadline
- [ ] Requirements and critical conditions
- [ ] Evidence plan
- [ ] Contradiction treatment
- [ ] Stop conditions
- [ ] Action authority
- [ ] Outcome measures
- [ ] Reassessment trigger

## Publication

- [ ] Default is no publication
- [ ] Sanitization authority documented
- [ ] Technical, confidentiality, IP, security, and export reviews required
- [ ] Final human release approval required
