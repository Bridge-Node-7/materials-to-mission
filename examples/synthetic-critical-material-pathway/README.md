# Synthetic Critical-Material Pathway

Every entity, record, material, supplier, facility, mission, method, and result in
this directory is fictional. The example demonstrates unknown evidence,
contradictory evidence, a triggered noncompensating critical condition, a human
`HOLD` disposition, and a reassessment path.

It does not describe a real material, supplier, customer, facility, laboratory,
capacity, vulnerability, mission, or qualification state.
