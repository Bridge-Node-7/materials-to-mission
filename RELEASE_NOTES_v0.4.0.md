# Materials-to-Mission v0.4.0 — Validation Profile Compatibility Closeout

v0.4.0 is a profile-compatibility-only minor release over immutable v0.3.1.

It restores `m0-strict-0.2.0` to its released accept/reject behavior and adds
`m0-strict-0.4.0` as the new default profile carrying the explicitly versioned rejection
of `Scoring Engine`, `Rules Engine`, and `Inference Service` as automation authorities.

This release does not change canonical v0.1.0 schemas, browser source or behavior,
GA-001 v1.0.0 evidence, public-view contract 0.3.0, website integration, M0 maturity,
the no-score rule, or human consequential authority.
