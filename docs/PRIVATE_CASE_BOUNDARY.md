# Private Case Boundary

A real Materials-to-Mission case should not be placed in this public repository.

Before accepting real records, establish the contracting entity, confidentiality
terms, data authority, storage, access controls, retention, deletion, incident
response, restricted-information screening, intellectual-property boundaries,
approved AI use, reviewers, and final decision authority.

A public release may contain only a sanitized derivative that has been reviewed
and authorized for publication. Sanitization must remove identities, exact
technical thresholds, supplier and laboratory details, pricing, capacity,
vulnerabilities, customer context, patent-sensitive methods, and restricted
information.
