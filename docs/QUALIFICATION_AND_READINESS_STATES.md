# Qualification and Readiness States

Keep these dimensions separate.

## Qualification lifecycle

```text
NOT_STARTED
PLANNED
FUNDED
SAMPLE_RECEIVED
TESTING
COMPLETED
```

## Qualification result

```text
NOT_DETERMINED
QUALIFIED
CONDITIONALLY_QUALIFIED
FAILED
```

## Commercial availability

```text
IDENTIFIED
CONTACTED
WILLING
CONTRACTABLE
AVAILABLE_WITHIN_NEED_DATE
NOT_AVAILABLE
```

## Production readiness

```text
NOT_ASSESSED
CAPACITY_UNVERIFIED
CONTRACTUALLY_UNAVAILABLE
PRODUCTION_READY
SURGE_READY
```

## Permanent distinctions

Finding a supplier does not prove the material will work.

Traceability does not equal qualification. Qualification does not equal production
readiness. Repository validation does not equal authorization.

These states describe a future multi-dimensional operating model. They do not change the
current public schema without a separately reviewed, evidence-backed version decision.
