# Gallium Public Storyboard

## Purpose

Gallium is the first public material used to demonstrate the Materials-to-Mission visual
experience against public-source evidence. It is a **public-source evidence snapshot**, not
a real operational Case 001 and not a new canonical schema authority.

The permanent distinction is:

- synthetic cases prove the method;
- public-source snapshots demonstrate the method against reality;
- private operational cases use the method consequentially.

## Golden Journey

### 1. Arrival

The user understands the promise quickly:

**See the pathway. Verify the constraint. Direct the next move.**

No readiness score, urgency theater, or unsupported claim is shown.

### 2. Materials Atlas

Gallium appears inside a restrained field of materials and mission dependencies. The atlas
is orienting, not a broad supplier database.

### 3. Gallium Focus

The experience establishes the material, the defined public evidence scope, the review
date, and the distinction between observed facts and inferred pathway implications.

### 4. Trace to Mission

The flagship visual trace follows:

**MATERIAL → PROCESSING → REQUIRED FORM → FABRICATION → COMPONENT → VALIDATION →
QUALIFICATION → ACQUISITION ACCESS → SYSTEM → MISSION**

Unknown or unsupported links remain visibly unknown or unsupported.

### 5. Show Support

Every material claim or pathway state may reveal:

- source identity;
- source date;
- observed statement;
- interpretation boundary;
- validation profile;
- unresolved evidence needs;
- provenance and review date.

### 6. Examine

The user moves from the dark exploratory field into a warm evidence-review surface. The
interface explains what the evidence supports and what it does not establish.

### 7. Decision Room

The experience presents evidence-supported action options using the bounded action ladder:

**Monitor → Validate → Support → Accelerate → Surge**

Consequential authority remains human. No action is automatically approved or closed.

## Public Claim Rule

When evidence is absent, the public experience uses bounded language such as:

> No qualifying public evidence was identified within the defined search scope as of the
> review date.

Absence is not converted into low risk, favorable readiness, or proof that a condition does
not exist.

## Data Gate

No Gallium snapshot belongs in the repository until DATA-00 separately proves source
identity, public usability, scope, rights, dates, provenance, and the absence of protected
or unsupported content.
