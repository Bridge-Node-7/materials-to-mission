# Public Boundary

## Allowed Public Content

- Public method documentation
- Versioned schemas
- Synthetic examples
- Public validation logic
- Sanitized templates
- Release evidence
- General limitations

## Excluded Content

- Real suppliers, customers, laboratories, facilities, samples, lots, prices, capacities, or vulnerabilities
- Patent-sensitive implementation or unpublished invention details
- Controlled unclassified information, classified information, or export-controlled technical data
- Proprietary qualification thresholds or private scoring logic
- Nonpublic test data, agreements, partner discussions, or source relationships
- Unsupported certification, qualification, compliance, government, production, or adoption claims

Public-boundary scanning is a guardrail, not a substitute for human review.
