# Public Boundary

## Allowed Public Content

- Public method documentation
- Versioned canonical schemas
- Versioned derived public view contracts
- Synthetic examples
- Separately reviewed public-source evidence snapshots with explicit provenance and rights
- Public validation logic
- Sanitized templates
- Release evidence
- General limitations
- Public visual design tokens and non-authoritative presentation logic

## Excluded Content

- Real suppliers, customers, laboratories, facilities, samples, lots, prices, capacities,
  or vulnerabilities unless separately authorized for a bounded public-source snapshot
- Patent-sensitive implementation or unpublished invention details
- Controlled unclassified information, classified information, or export-controlled
  technical data
- Proprietary qualification thresholds or private scoring logic
- Nonpublic test data, agreements, partner discussions, or source relationships
- Unsupported certification, qualification, compliance, government, production, adoption,
  or commercial-readiness claims
- Private operational Case 001 records
- Browser write-back that mutates canonical records
- Autonomous consequential decisions

## Public Visual Layer

The public browser is a derived, read-only, non-authoritative presentation layer. Public
source absence must not be presented as low risk or favorable readiness. A supported claim
must not be presented as an approved pathway. Governing or triggered conditions are
overlays, not evidence states.

Public-boundary scanning is a guardrail, not a substitute for human review.
