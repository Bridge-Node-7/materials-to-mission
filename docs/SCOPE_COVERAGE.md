# Scope Coverage

## Implemented in M0

Materials-to-Mission provides a public-safe method, versioned schemas, deterministic local
validation and rendering, synthetic examples, a Material Assurance Record, a Decision
Passport, visible uncertainty, noncompensating critical conditions, human-owned
dispositions, public-boundary scanning, and reproducible release evidence.

## Evidence-gated future work

- one protected M1 Real Case 001;
- independent real-case review;
- measured outcome and intended-user evaluation;
- repeated delivery and reassessment;
- bounded import formats;
- a thin Frontier Decision Engine adapter;
- a browser-local guided experience;
- sanitized lessons only when separately authorized.

## Private and protected work

Real customers, suppliers, facilities, samples, lots, laboratories, qualification
thresholds, prices, capacity, ownership analysis, mission vulnerabilities, contracts,
controlled information, export-controlled data, and patent-sensitive methods remain in
approved private systems.

## Permanently excluded authority

This repository does not issue qualification, certification, compliance, legal ownership,
FOCI, waiver, procurement, production-readiness, government-approval, or operational
authorization decisions.

## Portfolio ownership

Materials-to-Mission owns the canonical public record contracts. The Bridge Node 7 website
provides narrative and routing. Other repositories may consume released contracts but may
not redefine them.
