# Start Here

Materials-to-Mission asks one question:

> Does the available evidence justify a defined next action for a specific material, source, process, component, or mission dependency?

## Seven-Step Method

1. Define the decision and named human authority.
2. Record requirements and noncompensating critical conditions.
3. Collect source-linked evidence without hiding uncertainty or contradiction.
4. Build the Material Assurance Record.
5. Generate the Decision Passport.
6. Obtain independent review where the consequence warrants it.
7. Record the human disposition, action, outcome, and reassessment trigger.

## Fastest Evaluation

Run `python scripts/evaluate_public_method.py`, then inspect `build/guided-decision-passport.md`.

The synthetic reference case teaches structure only. GA-001 is separately identified as a bounded reviewed public-source snapshot.
