# Maturity and Proof

## Current status

Materials-to-Mission is **M0: Experimental Public Method**.

M0 means the public method, schemas, validation, rendering, synthetic fixtures, public-source evidence examples, and explicit limitations are available for inspection and use.

M0 does **not** establish real-world qualification, certification, acquisition approval, mission readiness, commercial validation, external adoption, or operational authorization.

## What supports the M0 claim

- versioned public method and schemas;
- deterministic validation and release artifacts;
- synthetic reference cases;
- bounded public-source evidence examples;
- visible unknown and critical-condition handling;
- human consequential authority;
- documented public limitations.

## Higher-maturity boundary

Any stronger maturity claim would require evidence beyond the public method itself, including independently reviewable real-world application and outcome evidence. This repository does not claim that evidence.

See [`CURRENT_STATE.md`](CURRENT_STATE.md) for the current public status.
