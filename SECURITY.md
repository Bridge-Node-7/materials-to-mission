# Security Policy

## Supported Version

Security fixes are applied to the latest public release.

## Reporting

Do not disclose a vulnerability, sensitive record, secret, supplier identity,
customer information, laboratory result, sample, lot, patent-sensitive method,
or restricted technical information in a public issue.

Use GitHub private vulnerability reporting when enabled. Otherwise contact
Bridge Node 7 through the Strategic Inquiry path on the company website and
state only that a private security report is available.

Include reproduction steps, affected version, impact, and a minimal public-safe
example. Do not include live credentials or protected data.
