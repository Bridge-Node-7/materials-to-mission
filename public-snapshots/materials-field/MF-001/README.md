# MF-001 — Public Materials Field Snapshot

MF-001 is the public input for the Materials-to-Mission Strategic Constellation.

It contains:
- the exact 60-mineral USGS 2025 critical-mineral field;
- the 15 rare-earth flags on that list;
- controlled DOE application rows used to derive BN7 Application Lenses;
- public engineered-form relationships;
- public source metadata.

MF-001 does not claim that all 60 minerals have a reviewed Materials-to-Mission pathway. Gallium remains the only material in this release with a released reviewed pathway through GA-001.

The six Application Lenses and constellation coordinates are a Bridge Node 7 presentation ontology. They are navigation aids derived from source application memberships, not an official government taxonomy, importance ranking, risk score, readiness score, investment recommendation, qualification, or approval.

This public snapshot is allowlisted. It does not enumerate records outside the public input.
