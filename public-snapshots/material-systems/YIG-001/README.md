# YIG-001 — Public Material-System Pathway

YIG-001 is a bounded public research-context pathway for yttrium iron garnet.

It is intentionally distinct from GA-001:
- GA-001 is the released Gallium Reviewed Pathway.
- YIG-001 is Reviewed Public Context with a full Materials-to-Mission chain and an explicit Evidence Horizon.

YIG is an engineered material system, not a USGS critical mineral. The record links its critical-mineral dependencies and public peer-reviewed evidence without exposing private supplier, laboratory, or patent-sensitive implementation details.
