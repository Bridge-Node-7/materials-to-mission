# Materials-to-Mission v0.3.0 — M0 Public Visual Experience

v0.3.0 releases the first complete public visual Materials-to-Mission experience while
preserving the method's evidence and authority boundaries.

## Included

- Seven-stage Golden Journey: Arrival → Materials Atlas → Gallium → Trace to Mission →
  Show Support → Examine → Decision Room.
- GA-001 v1.0.0 Gallium public-source evidence snapshot.
- Derived public view contract 0.3.0.
- Read-only static browser with no backend, telemetry, account system, remote persistence,
  or write-back.
- Verified production deployment at `https://bridgenode7.com/materials-to-mission/`.
- Observed accessibility, reduced-motion, narrow-viewport, privacy, security, and
  performance validation.

## Preserved authority

- Canonical schema authority remains immutable v0.1.0.
- Validation profiles remain independently versioned; no new ERROR semantics are introduced.
- Python semantic validation remains authoritative.
- GA-001 is not an operational Case 001.
- Public maturity remains M0.
- Evidence informs; humans decide; responsibility remains human.

## Release evidence

The signed annotated tag, immutable GitHub Release, release manifest, deterministic archive,
